# sla-itsm-workflow-api
Production-ready Enterprise SLA &amp; ITSM REST API built with Java 21 LTS and Spring Boot 4. Demonstrates Clean Architecture, Hibernate/JPA concurrency control (@Version), RFC 7807 problem details, and 80%+ unit test coverage with Mockito.

## Futtatás
- Terminal (Gradle): `./gradlew bootRun`
- IntelliJ IDEA: A `.run/sla-api-backend.run.xml` config is available in IDE.
